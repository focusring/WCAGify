# 18: Explore-mode guidance, consent texts and pilot packaging

**What to build:** Explore mode gets its guidance copy (visit every part of the target in scope, load important pages directly by address, use a test account) and a consent screen before the first capture explaining what is recorded, the debugger bar and that nothing is sent anywhere, in Dutch and English. The release workflow builds the capture extension and attaches a zip and a packed extension file to the GitHub release. Install documentation covers Chrome, Edge, Brave, Arc and Vivaldi, and a pilot checklist tells the evaluator what to send a commissioner.
