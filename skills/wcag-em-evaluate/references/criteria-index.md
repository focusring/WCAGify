# Success criteria index

One file per WCAG 2.2 success criterion of Level A and AA in [criteria/](criteria/): the
requirement, what axe-core settles, the manual procedure, how to decide and how to report. "Since"
is the first WCAG version that has the criterion; a report targeting an earlier version does not
evaluate later ones. The group is the pass of [groups.md](groups.md) that settles it. 4.1.1 is
obsolete in WCAG 2.2 and evaluated only for 2.0 and 2.1 targets. Level AAA criteria have no file
yet: a report with `targetLevel: AAA` evaluates them from the W3C Understanding documents directly,
following the same template.
